LIST GENERATOR 7000

This folder is a shareable copy of the List Generator 7000 app. It contains the files needed to install and run the app, plus the bundled city map and EE workbook template.

This copy is generated by build_standalone.sh in the main project folder. Make changes there and rebuild rather than editing these files.

REQUIREMENTS

- macOS or Linux
- Python 3.9 or newer
- Access to the registration API
- OAuth client credentials: CLIENT_ID and CLIENT_SECRET

FIRST-TIME SETUP

1. Copy .env.example to .env.
2. Edit .env and replace the placeholder values for CLIENT_ID, CLIENT_SECRET, and FLASK_SECRET_KEY.
3. Run ./run_list_generator_7000.command.

The launcher creates a local .venv environment and installs the packages in requirements.txt automatically. The app normally starts at http://127.0.0.1:8050.

Alternatively, run it manually:

python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python list_generator_7000.py

INCLUDED FILES

- list_generator_7000.py: main Dash application
- prebuilt_reports_7000.py: report generation logic
- national_inventory_workflow.py: National Inventory workflow
- Cities_Extended_Mapped.csv: city-to-campus mapping
- assets/EE_Sport_Template_Blank.xlsx: EE Sport Template source workbook
- .env.example: configuration template
- requirements.txt: Python dependencies
- run_list_generator_7000.command: macOS/Linux launcher

CONFIGURATION

The default API endpoints target https://apps.csipacific.ca and use Registration API v2, which requires your account to have an active acting profile and the Registration permissions for the data you report on. To fall back to the unversioned v1 API, set REGISTRATION_API_BASE=https://apps.csipacific.ca/api/registration/ in .env. To use another environment, set SITE, AUTH_URL, TOKEN_URL, REGISTRATION_API_BASE, and ACTOR_URL in .env.

Do not share a completed .env file. Each user should create their own credentials and secret key.

OPTIONAL UPLOADS

The National Inventory workflow accepts AAP or COPSIN data as CSV, XLSX, XLSM, or XLS uploads from the browser. The EE Sport Templates workflow accepts the CAC coach report the same way. Those source files do not need to be included in this folder.
