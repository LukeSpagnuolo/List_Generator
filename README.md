# List Generator Lite

A Dash app for building profile and nomination lists from the CSI Pacific
Registration system (Registration API v2). Each user signs in with their own CSI
apps account, and the app only shows the data that account can see.

- **Custom export:** choose the fields, filter by campus, enrollment status, role,
  sport, nomination fiscal year, carding level, nomination status and organization,
  preview the result, and download a CSV.
- **Prebuilt reports:** standard lists (unclaimed nominations, mail merge, ViaSport
  LOU, Enhanced Excellence, SC Carded, High Performance, Coaches, and more).
- **National Inventory:** service reports from Registration, AAP or COPSIN data.

> This repository is generated by a build script. Changes made directly here are
> overwritten by the next build.

## Settings (environment variables)

| Variable | Required | Value |
| --- | --- | --- |
| `CLIENT_ID` | Yes | OAuth client ID from CSI apps |
| `CLIENT_SECRET` | Yes | OAuth client secret from CSI apps |
| `FLASK_SECRET_KEY` | Yes | A long random string. Keep it the same between deploys, or everyone is signed out. Generate one with `python3 -c "import secrets; print(secrets.token_hex(32))"` |
| `APP_URL` | Yes | The app's public URL, **without** a trailing slash, e.g. `https://connect.example.org/content/1a2b3c4d` or a vanity URL |
| `REGISTRATION_API_BASE` | No | Set to `https://apps.csipacific.ca/api/registration/` to fall back to the v1 API |

**Sign-in redirect.** The OAuth client in CSI apps must list `<APP_URL>/redirect`
as an allowed redirect URI, for example
`https://connect.example.org/content/1a2b3c4d/redirect`. Each place the app runs
(Posit, a laptop at `http://127.0.0.1:8050`) needs its own entry.

## Deploy on Posit Connect

**From Git (recommended):**

1. In Posit Connect: **Publish → Import from Git**, repository
   `https://github.com/LukeSpagnuolo/List_Generator`, branch `main`, directory `/`.
   Connect reads `manifest.json`, so you don't need to choose the app type or entry point.
2. Open the content's **Vars** panel and add `CLIENT_ID`, `CLIENT_SECRET`,
   `FLASK_SECRET_KEY` and `APP_URL`. Mark the client secret and the secret key as secret.
   - `APP_URL` is the content URL shown in Connect, or the vanity URL if you set one.
     If you change the vanity URL later, update `APP_URL` and the redirect URI in CSI apps too.
3. Add `<APP_URL>/redirect` to the OAuth client's redirect URIs in CSI apps.
4. Restart the content and open it. You should be sent to the CSI apps sign-in.
5. Under **Access**, choose who can open it.

Connect then redeploys automatically when `main` changes. If the server doesn't
have Python 3.12, edit `"version"` under `"python"` in `manifest.json` to a
version it has (3.9 or newer).

**From your computer, instead of Git:**

```bash
pip install rsconnect-python
rsconnect deploy manifest manifest.json --server https://<your-connect-server> --api-key <key>
```

## Deploy on Posit Connect Cloud

Create a **Dash** app from this repository (branch `main`, primary file `app.py`,
Python 3.12). Add the same four variables under **Secrets**, and register
`<APP_URL>/redirect` in CSI apps.

## Run locally

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt     # Windows: .venv\Scripts\pip ...
cp .env.example .env                          # then fill in CLIENT_ID and CLIENT_SECRET
.venv/bin/python app.py
```

Open http://127.0.0.1:8050 and sign in.

## Data handling

Exports can contain personal information (dates of birth, guardian contacts).
Sensitive fields are left out unless the user selects them. Fetched data is kept
in a temporary cache on the server for up to two hours
(`LIST_GENERATOR_CACHE_TTL_SECONDS`) so the user can filter and download it.
Never commit a completed `.env` file.
